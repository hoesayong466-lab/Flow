# SolidWorks 파일 웹 업로드·열람 가이드

> 기준: 2026-11-16 배포본(7번 버전)

## 지금 웹에서 확인하는 방법

1. [설비 프로젝트 진행 관리](https://equipment-project-flow.decent-elf-8236.chatgpt.site)에 접속합니다. 현재 사이트는 소유자 계정만 볼 수 있습니다.
2. 휴대폰에서는 왼쪽 위 메뉴(☰)를 열고 프로젝트를 선택합니다.
3. 프로젝트 상단의 **자료** 탭을 누릅니다.
4. 목록에서 조립품·부품·2D 도면을 고릅니다.
   - 조립품·부품: 3D 보기에서 회전하고 확대합니다.
   - 2D 도면: 확대·축소 버튼으로 치수를 확인합니다.

## 새 SolidWorks 파일을 추가하는 방법

**현재 배포된 웹에는 CAD 파일을 직접 올리는 버튼이 없습니다.** 자료 화면은 이미 웹용으로 변환된 파일 목록을 읽어 보여줍니다. 화면에 보이는 CAD 자산은 3D용 3MF와 도면용 PDF로 준비되어 있습니다. 발주 등록 화면의 엑셀 첨부는 발주서용이며 SolidWorks 업로드와는 별개입니다.

현재 새 파일을 추가할 때는 다음 순서로 진행합니다.

1. SolidWorks에서 최상위 조립품을 열고 **Pack and Go**로 참조 파일을 함께 모읍니다.
2. 부품 파일(`.SLDPRT`), 조립품 파일(`.SLDASM`), 도면(`.SLDDRW`)이 포함됐는지 확인하고 ZIP으로 저장합니다. 조립품 파일 하나만 보내면 연결된 부품을 찾지 못할 수 있습니다.
3. 이 Codex 대화에 ZIP을 첨부합니다. 단품만 추가할 때는 해당 부품과 필요한 도면을 첨부해도 됩니다.
4. 대상 프로젝트와 대표 조립품, 웹에서 확인할 도면을 알려줍니다.
5. 파일을 웹에서 열 수 있게 변환해 사이트 자료에 반영하고 배포하면, 같은 프로젝트의 **자료** 탭에서 확인할 수 있습니다.

## 사이트에서 직접 업로드하려면

직접 업로드는 아직 구현되지 않았습니다. 기능이 추가되면 사용자 동선은 아래처럼 됩니다.

**프로젝트 선택 → 자료 → CAD 업로드 → Pack and Go ZIP 선택 → 서버에서 참조 확인·웹용 변환 → 미리보기 확인 → 자료에 등록**

이 흐름에는 웹 업로드 화면뿐 아니라 파일 저장소, SolidWorks 파일 변환 처리, 참조 파일 누락 확인, 변환 결과 미리보기가 필요합니다. 따라서 현재는 위의 Codex 첨부 방식으로 새 CAD 자료를 반영합니다.
